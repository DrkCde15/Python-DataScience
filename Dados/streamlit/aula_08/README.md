# Fazer deploy de sites usando Streamlit

📋 Pré-requisitos
Para que o deploy funcione corretamente, o projeto deve conter o arquivo de dependências:
requirements.txt: Contém todas as bibliotecas necessárias para o seu código rodar (gerado com pip freeze > requirements.txt).

🌐 Como fazer o Deploy (Passo a Passo)

1 Preparação: Garanta que seu código Python (aula_08.py, por exemplo) e o arquivo equirements.txt estejam na raiz do repositório GitHub.

2 GitHub: Suba os arquivos para um repositório público no seu perfil.

3 Streamlit Cloud:
- Acesse streamlit.io.
- Conecte sua conta do GitHub.
- Clique em "New App" e selecione o seu repositório.
- Configure o arquivo principal (ex: aula_08.py) e defina a URL personalizada.
- Clique em "Deploy".
