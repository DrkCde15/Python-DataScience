# Streamlit - Aplicações Web Interativas

Scripts para **criação de aplicações web interativas** usando Streamlit. São 16 aulas progressivas, do básico ao avançado.

## Estrutura

```
streamlit/
├── aula_01/          # Primeiros passos: st.title, st.header, st.markdown
├── aula_02/          # Layout: sidebar, columns, botões, sliders, images
├── aula_03/          # Dados: DataFrames, tabelas, gráficos, upload de arquivos
├── aula_04/          # Estado: st.session_state, st.cache_data
├── aula_05/          # Visualização: Matplotlib, Plotly, Altair
├── aula_06/          # Widgets: selectbox, multiselect, radio, forms
├── aula_07/          # Customização: st.set_page_config, st.status, config.toml
├── aula_08/          # Calculadora (revisão)
├── aula_09/          # Integração: SQLite + API REST
├── aula_10/          # App multi-páginas com option_menu
├── aula_11/          # Navegação com st.navigation
├── aula_12/          # PDF: merger e visualizador
├── aula_13/          # Métricas: st.metric com sparklines
├── aula_14/          # Abas: st.tabs
├── aula_15/          # Editor de dados: st.data_editor
└── aula_16/          # Diálogos e popovers: st.dialog, st.popover
```

## Conceitos abordados

- Elementos de texto e markdown
- Layout com colunas, sidebar e containers
- Estado de sessão e caching
- Visualização com Matplotlib, Plotly e Altair
- Widgets de entrada (inputs, seletores, formulários)
- Integração com SQLite e APIs REST
- Aplicações multi-páginas
- Manipulação de PDFs
- Métricas, abas, editor de dados
- Diálogos modais e popovers
