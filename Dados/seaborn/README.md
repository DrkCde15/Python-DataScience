# Seaborn - Visualização Estatística

Scripts para visualização estatística de dados usando **Seaborn**, construído sobre o Matplotlib.

## Arquivos

| Arquivo | Descrição |
|---------|-----------|
| `grafics_sns.py` | Gráficos de dispersão, histogramas, distribuições KDE, regressão linear e gráficos relacionais com dados de arquivo Excel |

## Conceitos abordados

- `sns.scatterplot()` com `hue`, `style`, `palette`
- `sns.relplot()` com subplots por categoria
- `sns.lineplot()`
- `sns.displot()` nos modos `hist`, `kde`, `ecdf`
- `sns.regplot()` e `sns.lmplot()` para regressão linear
