# Folium - Visualização de Mapas

Notebooks Jupyter para **criação e manipulação de mapas interativos** usando a biblioteca Folium.

## Arquivos

| Arquivo | Descrição |
|---------|-----------|
| `mapa1.ipynb` | Criação de mapa base com marcadores |
| `mapa2.ipynb` | Personalização de mapas com diferentes tiles e camadas |
| `mapa3.ipynb` | Mapas com múltiplas camadas e interatividade |

## Diretórios

- `graficos/` - Assets gráficos para mapas
- `mapas/` - Mapas gerados/salvos

## Conceitos abordados

- `folium.Map()` com diferentes tiles
- `folium.Marker()` e popups
- Camadas (Layer Control)
- Mapas interativos para visualização geoespacial
