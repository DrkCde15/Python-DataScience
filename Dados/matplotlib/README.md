# Matplotlib - Visualização de Dados

Scripts para criação e personalização de gráficos usando **Matplotlib**, a biblioteca padrão de visualização do Python.

## Arquivos

| Arquivo | Descrição |
|---------|-----------|
| `grafics_plt.py` | Gráficos de linha, dispersão e barras; subplots; personalização de eixos, legendas, cores e estilos |
| `grafics_pd_plt.py` | Leitura de CSV com Pandas, filtragem de dados e visualização de séries temporais em múltiplos subplots |

## Conceitos abordados

- `plt.plot()`, `plt.scatter()`, `plt.bar()`
- Personalização: `linestyle`, `color`, `lw`, `label`, `legend`
- `plt.axis()`, `plt.xticks()`, `plt.yticks()`
- `fig.add_subplot()` para múltiplos gráficos
- `plt.savefig()` para exportar imagens
- Integração Pandas + Matplotlib
