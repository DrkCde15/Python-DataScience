# NumPy - Arrays e Operações Vetoriais

Scripts de introdução ao **NumPy**, a biblioteca fundamental para computação numérica em Python.

## Arquivos

| Arquivo | Descrição |
|---------|-----------|
| `arrays.py` | Criação de arrays, operações vetoriais, indexação, fatiamento (slicing), matrizes especiais (`zeros`, `ones`, `eye`) e geração de números aleatórios |

## Conceitos abordados

- Criação de arrays a partir de listas
- Operações vetoriais (+, -, *, /)
- `np.arange()`, `np.linspace()`
- `np.random.rand()`, `np.random.randn()`, `np.random.randint()`
- Matrizes identidade, zeros e uns
- Indexação e slicing em 1D e 2D
